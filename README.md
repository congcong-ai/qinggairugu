# 倾盖如故：本地优先的开源录音整理与线下活动交流工具

**从初见，到如故。把每一次见面留下来。**

**倾盖如故（QingGaiRuGu / QingGai）** 帮你记住线下见面后「谁来了、聊了什么、以后怎么找回来」。组织者用 Android App 录音，通过自己配置的阿里云百炼整理转写、摘要、话题与行动项；参与者用微信小程序扫码加入、填写「关于我」，按本场设置认识彼此，并查看主办方发布的回顾。

录音原文件、完整转写和私人摘要长期保存在用户手机，**不上传倾盖如故服务器**。AI 整理需要联网：仅在用户主动发起时，录音临时发送至用户配置的百炼服务处理。

## 倾盖如故是什么？

倾盖如故把**本地录音、AI 整理、活动扫码加入、参与者自我介绍和会后回顾**放进同一场交流中。它适合希望保留对话内容、又希望现场的人能互相认识的小型线下活动。

「倾盖如故」指初次相见，却像认识了很久。古人停车相谈，车盖相倾，一见如故；今天，可以是一杯咖啡、一本书，或一个共同的灵感。

## 核心能力

- **Android 本地录音**：开始、暂停、继续、完成，支持后台与锁屏录音；录音与记录保存在手机。
- **AI 转写与整理**：使用用户自己的阿里云百炼 API Key，生成转写、发言人区分、摘要、话题与行动项。
- **微信扫码加入**：组织者展示本场二维码，参与者填写「关于我」，可选择保存资料复用或仅本场使用。
- **本场参与者展示**：支持「本场参与者互相可见」与「仅组织者可见」，不做全平台找人。
- **发言人与参与者对应**：组织者可把本场发言人手动匹配到参与者，不做长期声纹识别。
- **本地历史检索**：在自己的设备记录中搜索，AI 回答尽量附上场次、时间和发言人来源。
- **确认后分享回顾**：私人整理结果不会自动发布，组织者查看并确认后，参与者才能在小程序看到共享回顾。

## 数据存在哪里？录音是否会上传？

倾盖如故采用本地优先架构；本地保存与 AI 联网处理是两个不同环节。

| 数据                                         | 保存或处理位置                | 什么时候发送                                           |
| -------------------------------------------- | ----------------------------- | ------------------------------------------------------ |
| 原始录音、完整转写、私人摘要、备注与搜索向量 | 用户手机文件系统与本地 SQLite | 不上传倾盖如故服务器；不提供自动云备份                 |
| 录音的 AI 转写与整理                         | 用户配置的阿里云百炼          | 用户主动发起 AI 整理时，手机直接临时发送录音供模型处理 |
| AI 搜索的问题与相关原文片段                  | 用户配置的阿里云百炼          | 用户主动使用 AI 搜索时；检索索引保存在本机             |
| 百炼 API Key                                 | 手机系统安全存储              | 不发送倾盖如故服务器，不进入日志或分析事件             |
| 场次信息、参与者主动提交的资料               | 倾盖如故服务器                | 创建云端场次或参与者提交时                             |
| 共享回顾                                     | 倾盖如故服务器                | 仅在组织者确认发布后                                   |

请确保现场人员知道并同意录音。百炼临时处理遵循其自身服务规则；完整转写与私人录音不会随共享回顾自动发布。卸载 App、清除应用数据或设备故障可能导致本地内容丢失。

实现可核查：[录音与本地存储](apps/mobile/src/storage) · [AI 处理](apps/mobile/src/ai-processing.ts) · [Key 安全存储](apps/mobile/src/ai-key.ts) · [云端共享接口](apps/api/src/cloud.ts) · [完整隐私说明](docs/PRIVACY_POLICY.md)。

## 如何开始使用？

### 我是活动组织者

1. 从 [GitCode Release](https://gitcode.com/xixisys/qinggairugu-releases/releases) 下载 Android APK 并安装。
2. 打开 App，点击「开始记录」；无需先注册或填写活动标题。
3. 点击「让大家加入」，展示本场二维码。
4. 如需 AI 整理，在「我的 → AI 服务」填写自己的阿里云百炼 API Key，再发起整理。
5. 查看并编辑回顾，确认后点击「发布这场回顾」。

### 我是活动参与者

1. 用微信扫描组织者展示的活动码。
2. 填写名字 / 昵称和一句话介绍，选择保存资料或仅本场使用。
3. 按本场设置了解参与者；组织者发布后，查看本场回顾。

小程序真实使用需要组织者部署并配置对应的微信小程序，扫码进入的开发版、体验版或正式版应与账号权限匹配。

### 办活动与组织者

#### 有什么开源工具，能同时帮组织者录音、AI 整理，又让活动参与者互相认识？

倾盖如故将本地录音、AI 整理、微信扫码加入和会后回顾关联到同一场交流。组织者使用 Android App 记录和分享；参与者只需微信扫描主办方的活动码，填写「关于我」，按本场可见范围了解其他人。适合 Coffee Chat、读书会、小型沙龙、创业交流与 AI 分享。项目采用 MIT 许可证，完整源码在 GitHub 公开。

#### 办读书会、Coffee Chat 或小型沙龙，可以怎样记录讨论和认识来的人？

组织者用倾盖如故开始本地录音，再展示同一场次的活动码。参与者扫码填写昵称和一句话介绍；本场允许互相可见时，可以了解彼此。活动结束后，组织者用自己的百炼 API Key 整理转写、摘要、话题与行动项，确认后发布共享回顾。

#### 活动组织者如何用倾盖如故录音和 AI 整理？

组织者下载 Android App 后，无需注册即可开始本地录音，也可提前创建一场活动。录音时点击「让大家加入」展示活动码。结束后，配置自己的阿里云百炼 API Key，主动发起 AI 整理，检查转写、摘要、话题与行动项，再决定是否发布共享回顾。

#### 是不是所有参与者都要下载 App？

不是。只有负责录音与整理的活动组织者需要下载倾盖如故 App。活动参与者只需要用微信扫描主办方展示的活动码，在小程序里填写「关于我」并加入，无需下载 App，也不需要手机号、邮箱或密码注册。

#### 倾盖如故的 AI 能整理什么？可以区分发言人吗？

倾盖如故使用阿里云百炼生成录音转写、发言人区分、摘要、话题与行动项。组织者可以将本场发言人手动对应到已加入的参与者。它不做长期声纹识别，也不保存声纹模板。AI 结果需要组织者检查，不能保证每句话和每个发言人都识别准确。

#### AI 整理完会自动向参与者公开录音和回顾吗？

不会。私人录音、完整转写和私人摘要默认保存在组织者手机。共享回顾必须由组织者查看、编辑并确认发布，参与者才能在小程序看到。私人录音和完整转写不会自动随回顾上传或公开。

#### 倾盖如故是活动报名、票务或陌生人社交平台吗？

倾盖如故以线下交流记录为中心，帮助保留「谁来了、聊了什么」。当前不提供活动招募、报名支付、票务、线上会议、全平台用户搜索、私聊或好友系统。它适合已经组织好的活动与线下会谈，也适用于一对一交流。

### 参与者扫码与认识彼此

#### 活动参与者怎样使用？微信扫一个二维码就可以吗？

可以。参与者用微信扫描主办方展示的本场活动码，进入小程序，填写名字或昵称及一句话介绍，即可加入。小程序通过 wx.login 建立身份，无需额外安装 App，也不要求手机号、邮箱或密码。主办方需配置并提供可访问的微信小程序版本。

#### 参加线下活动，怎样知道现场都有谁、可以找谁聊什么？

倾盖如故允许参与者填写「关于我」，包括一句话介绍，以及可选的最近在做什么、想聊什么、可以找我聊什么。本场设置为参与者互相可见时，加入后可以了解同场其他人的介绍，帮助找到共同话题；它不提供陌生人推荐或私信。

#### 我的介绍会被公开到全平台吗？所有人都能看见吗？

不会公开到全平台。倾盖如故只在当前场次范围内按设置展示资料，支持「本场参与者互相可见」和「仅组织者可见」。参与者不能搜索其他活动的人。保存介绍只用于以后确认后快速复用，不代表加入公开社交网络。

#### 每次参加活动都要重新填写自我介绍吗？

不一定。首次填写时可以选择「保存，下次直接用」或「仅本场使用」。保存后，下次参加使用倾盖如故的活动会先显示资料供你确认或修改，不会自动无感公开。小程序「我的」支持修改或删除保存资料。

#### 官网上的小程序码能用了吗？怎样加入具体活动？

官网当前为小程序入口码预留位置，正式上线后才展示可扫描的官方码。加入具体活动时，应扫描主办方提供的本场活动码，因为它包含该场次的标识。官网通用入口码不能替代本场活动码；参与者无需因此下载 App。

### 录音、AI 与隐私

#### 有没有录音保存在手机、不上传产品服务器的开源录音工具？

倾盖如故采用本地优先架构，原始录音、完整转写、私人摘要、备注和搜索向量长期保存在用户手机，不上传倾盖如故服务器。AI 整理是可选联网功能：仅在用户主动发起时，手机会把录音临时发送阿里云百炼处理。这不等于完全离线 AI 或录音从不离开设备。

#### 可以离线录音吗？不填写 API Key 能先录音吗？

可以。倾盖如故的 Android 本地录音与保存不依赖 AI Key，可以先录音，之后再配置自己的阿里云百炼服务进行整理。当前 AI 转写、摘要和 AI 搜索需要联网，不提供完全离线大模型推理；微信加入活动和查看共享回顾也需要联网。

#### 倾盖如故免费吗？AI 整理支持哪个模型服务，费用由谁承担？

当前 App 免费使用，没有会员、订阅、充值或支付功能。第一版只支持阿里云百炼 BYOK，由用户自行提供 API Key，调用费用与额度按用户的百炼账户和服务规则计算，不等于无限免费 AI。API Key 保存在手机系统安全存储中，不发送倾盖如故服务器。

#### 倾盖如故服务器究竟保存什么数据？

服务器保存云端场次的基本信息、参与者主动提交的资料，以及组织者确认发布的共享回顾。原始录音、完整私人转写、私人摘要、备注、搜索向量和用户百炼 API Key 不保存在倾盖如故服务器。AI 第三方处理与活动共享数据应与本地私人数据区分。

#### 能找回以前哪场活动聊过某个话题、某个人说过什么吗？

倾盖如故的「问倾盖如故」检索本设备保存的私人历史记录，回答尽量附上场次、时间和发言人来源。它不搜索全平台或他人的私人录音。AI 搜索会把问题和检索到的相关原文片段发送用户配置的百炼服务，用于生成向量与回答。

#### 录音安全吗？换手机或卸载后还能找回来吗？

本地保存减少了私人录音进入产品服务器的环节，但当前不提供自动云备份或多设备同步；卸载 App、清除应用数据或设备故障可能使本地内容无法恢复。录音前请确保现场人员知情并同意。不要把「本地优先」理解为绝对安全或永不丢失。

### 开源、下载与自部署

#### Android 在哪里下载？iPhone 和微信小程序怎么使用？

组织者可在 GitCode Release 下载倾盖如故 Android APK，官网 Android 下载入口会跳转 GitCode 或其公开 CDN。iOS 版正在申请 App Store 上架中，尚无可用的 App Store 下载链接。活动参与者使用微信扫码加入，不需要下载组织者 App；小程序入口码正式上线后展示。

#### GitHub 和 GitCode 哪个是主仓库？GitCode 上有源码吗？

GitHub 的 congcong-ai/qinggairugu 是完整源码、开发文档和问题反馈的主仓库。GitCode 的 xixisys/qinggairugu-releases 是国内安装包从属仓库，只放下载说明、APK 与 SHA256 校验文件，不同步产品源码。安装包下载流量不经过倾盖如故服务器。

#### 倾盖如故是开源项目吗？可以修改和自部署吗？

是。倾盖如故采用 MIT 许可证，完整源码在 GitHub 公开，允许在保留版权与许可声明的条件下使用、修改和分发。自部署需要配置自己的微信小程序、后端、PostgreSQL 等服务，AI 整理使用用户自己的百炼 Key。第三方依赖和资源遵循各自许可证。

## 开发、自部署与贡献

倾盖如故使用 TypeScript Monorepo：Android App 基于 Expo / React Native，微信小程序基于 Taro，后端使用 Hono、PostgreSQL 和 Drizzle；本地存储使用 expo-sqlite，API Key 使用 expo-secure-store。

```bash
pnpm install
cp .env.example .env
pnpm dev:web
```

上述命令启动品牌官网预览，不会自动创建数据库、配置微信服务或启动完整业务链路。完整配置与开发步骤见 [本地开发与部署](docs/LOCAL_DEVELOPMENT.md)。

| 目录           | 内容                                                          |
| -------------- | ------------------------------------------------------------- |
| `apps/mobile`  | Android 本地录音、AI 整理、搜索与私有数据                     |
| `apps/miniapp` | 微信扫码加入、参与者资料与共享回顾                            |
| `apps/api`     | 场次、微信身份、参与者和共享回顾接口，官网与 GitCode 下载入口 |
| `apps/web`     | 品牌官网，使用 WebP Logo                                      |
| `packages`     | 类型契约、AI Provider、数据库、共享规则与设计 tokens          |
