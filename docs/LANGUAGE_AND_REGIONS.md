# 语言与地区约定

## 当前阶段：中国用户优先

倾盖如故 MVP 默认简体中文，覆盖首页、录音、权限用途、AI 设置、错误提示、小程序与共享回顾文案。当前不提供英文产品界面，也不要求用户手动切换语言。

本次真机看到的英文来自 Expo Custom Dev Client 的开发工具启动页和菜单，不是倾盖如故产品界面。排查使用的 debug 包会包含该工具；给用户验收的独立测试包与正式发布包应直接打开中文首页，不展示开发工具选择页。

## 后续国际版

继续使用同一个代码仓库和核心 Session 模型。发布区域与界面语言分别配置：

- 国内构建默认简体中文。
- 国际版在实际进入开发时加入中文、英文资源，自动按系统语言优先级选择；系统支持中文就使用中文，支持英文则使用英文，不支持时使用该地区构建的默认语言。
- 不通过 IP 或定位强制猜测用户语言。海外使用中文系统的用户同样可以看到中文。
- 可以同一 App 在多个地区上架；当后端、隐私文本、渠道能力或产品功能确实不同，再用构建配置输出不同包名的国内版/国际版，共用代码。仅为了语言不同，不复制两个独立项目。

国际版、跨地区后端及其他 AI 厂商属于未来范围，当前不提前实现。第一阶段继续完成中国用户的 Android + 微信小程序 + 百炼 BYOK 验收。

依据：[Android 多语言资源自动匹配](https://developer.android.com/training/basics/supporting-devices/languages)、[Expo 开发构建启动器](https://docs.expo.dev/develop/development-builds/introduction/)。
