用户已确认签名在另一台 Mac mini。应从原机复制整个 `~/.config/qinggai/signing/` 到本机，并同时复制 `release.env` 中 `PENGTOU_KEYSTORE_FILE` 指向的 `.jks` / `.keystore`（若在其他目录）。保留原私钥及密码，不重新生成签名；通过 AirDrop 或移动硬盘传输，不在聊天发送文件内容或密码。复制后核对配置路径和原证书，继续签名、覆盖安装及数据保留验收。

当前双架构、内置代码的未签名 Release 已完成原生构建、逐个 ARM64 ELF 16KB 校验及包内隐私检查，不等同于正式签名或真机验收。
