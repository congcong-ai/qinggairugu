## 现场联调接续步骤

1. Android 重新插线、解锁并确认 USB 调试，`adb devices -l` 显示 device 后继续；后续复查时设备已断开。
2. App 的“关联我的小程序”显示的是一次性文字关联码，不是活动加入二维码。活动二维码通过“我的活动 → 打开记录 → 让大家加入”生成，两者不可混淆。
3. 第二台手机扫码进入指定测试活动，点“加入这场”，填写明确的测试资料。核对同一 Session 的参与关系、人数及可见范围。
4. 绑定必须由本人在微信认领，再由 App 核对身份确认。已生成的一次性关联码可能已过期，应重新获取；不要保存码值到验收文档或日志。
5. 手机配置 BYOK 后继续真实 AI、显式文本同步与撤销、人工发布/修订/撤回及成员读取。录音与图片始终不在小程序显示。
6. 继续相机、三种格式、断网、长录和异常恢复专项；仍未完成的用例保留为待验收。
