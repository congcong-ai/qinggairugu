## 明确的功能限制

- App 本地原件不做自动云备份，卸载/清理应用数据可能丢失音频和图片。
- 云端私人文字是本人明确选择的副本，不提供原始音频或照片的跨设备读取。
- 同步需要联网；曾由本机同步的副本支持离线排队撤销，联网打开我的活动或再次同步前重试。排队不代表云端已删除，界面明确提示仍可能可见；真机离线联调待验收。
- 复杂多端冲突保留本机草稿并拒绝覆盖云端，当前需用户重新打开核对。
- 阶段 P8 尚未验收完成，不将本次代码标记为可正式发布。
