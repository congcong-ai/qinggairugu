# 双端导航与界面重构（2026-10-28）

## 审计结论与实现

App 原有四个 Tab 使用 Unicode 字符图标及固定高度；活动详情把改名、录音、AI、共享、删除混排。现改为统一线形图片图标、清晰标签、键盘弹出隐藏底栏，首页一个录音主操作、并排心得与发起入口；次要操作改为紧凑列表行。详情分为记录、本场共享、设置，删除与改名归入设置。二级页提供返回及无历史时回首页；页面保留安全区与滚动输入处理。

小程序保留原生「我的活动 / 我的」一级 Tab，并补图标；扫码活动属于二级页面，增加「这场 / 都有谁 / 回顾 / 我的活动」活动导航，切换携带本页 sid/scene 解析结果，不靠标题或日期匹配。全局收紧卡片、字号、表单和操作间距，加入列表加载与空态。实际工具截图发现 Taro 把 button 选择器编译成 h5-button，导致原生按钮不应用样式；改成明确 row-button 类后实际截图确认生效。

未改数据库、录音管线、媒体存储、AI Key 或同步接口。未部署、上传微信代码或覆盖正式下载文件。
