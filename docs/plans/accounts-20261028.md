# 账号与跨端数据升级（2026-10-28）

## 本轮已实现的服务端基础

新增迁移 0007，不修改 0001–0006。users.openid 保留为旧小程序身份兼容字段，允许新移动账号为空；wechat_identities 使用 AppID + OpenID 主键，wechat_unions 使用开放平台标识 + UnionID 主键。旧小程序首次登录接续原 user_id，既有活动、成员、绑定和私人文字关系不重写。

小程序 /auth/wechat 继续使用 jscode2session。新增 /auth/wechat/mobile 使用独立移动应用凭据在服务端交换 code。两接口都严格只接受 code，不能提交 OpenID、UnionID 或 user_id。仅微信响应提供的 UnionID 可用于账号解析；未配置开放平台标识或响应缺失 UnionID 时，保持独立身份，不按姓名猜测。两个已有账号分别积累数据后发生 UnionID 冲突时返回409，不做静默合并。

/auth/logout 撤销当前 bearer token；携带失效令牌的请求不会降级为匿名设备权限。原设备绑定协议仍保留，尚未切换 App 登录入口。

1. 接入原生 OpenSDK 与 Android 授权回调，生成并校验一次性 state，处理拒绝、取消、微信未安装。未获得资质前不能宣称真机微信登录通过。
2. SecureStore 保存产品登录令牌；退出清令牌和远端缓存，保留本机媒体。所有本机 Session、全文检索、照片及 AI 任务需要按账号归属过滤，避免仅在列表隔离而详情仍可越权。
3. 匿名历史首次登录展示显式认领清单，不自动把全机记录归当前账号。已归属记录禁止换号再次认领；原绑定设备的云端历史保持原用户，不通过新登录吞并。后台任务携带发起时账号和授权版本，切号后拒绝落盘/上传。
4. 私人 AI 同步从绑定归属迁到账号与来源设备归属，保留删除墓碑、版本条件更新和旧请求防复活。原绑定的私人结果不能随解绑或换号转给另一人。冲突保留双方版本，禁止静默覆盖；撤销只删除云端副本，本机原文保留，恢复必须重新确认。
5. 登录只建立身份。既有私人文字默认不同步；单场主动选择摘要、话题、行动项等字段。完整转写默认关闭，独立确认。共享回顾继续单独审核发布。
6. 普通登录在可信 UnionID 可用时无需关联码；缺失时明确无法打通，不能偷偷按身份猜测。保留旧关联作为兼容路径，不能假装已完成常规流程替换。
7. 双端 UI、权限、发起码自动加入及退出/换号回归后，再进行原签名覆盖安装和两实体微信联调。生产部署和正式下载覆盖未授权。

录音和照片保留独立本机副本，不上传本产品服务器，不让小程序读取；删除系统原图不影响副本，清数据或卸载会丢失，本机媒体不能换机恢复。AI 主动处理直达用户百炼。没有恢复 OSS、支付或社交能力。
