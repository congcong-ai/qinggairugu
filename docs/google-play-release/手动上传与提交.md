## 以后上传新版

1. 构建签名的 AAB，并使用比已上传版本更大的 versionCode。当前本地 AAB 为 artifacts/google-play/qinggairugu-0.2.3-7.aab。
2. Play Console 进入倾盖如故 → Test and release → Production → 编辑现有草稿（后续版本可创建新版本）。
3. 在 App bundles 点击 Upload，选择 .aab 文件，不选 .apk。保持该页面打开并等待 Google 完成处理；不要刷新、关闭或切换代理线路。
4. 若已成功入库，可用 Add from library 选择，避免重复上传。同一 versionCode 不能反复作为新版本上传。
5. 核对版本号，填写版本名称和说明，点击 Save as draft，再进入预览。

## 提交审核

补齐错误后，在生产版本预览点击 Save，将版本纳入待审核变更；随后进入 Publishing overview 核对变更，并点击 Send changes for review 提交审核。提交审核和最终上线不是同一状态；上线时机还取决于审核结果与托管发布设置。
