```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm build
TEST_DATABASE_URL=postgres://localhost:5432/postgres pnpm test
```

本轮结果：lint 通过、9/9 workspace 类型检查通过、9/9 构建通过、6 个测试文件共 19 项测试全部通过（包含 3 项真实 PostgreSQL 集成测试）。

测试使用真实 SQLite；PostgreSQL 集成测试在配置的实例中新建随机命名测试库，结束后只删除该测试库。未配置 `TEST_DATABASE_URL` 时，3 个 PostgreSQL 测试会跳过，不能据此宣称集成链路通过。

覆盖录音状态、参与者权限、资料复用、分块与余弦、百炼请求协议、speaker 本场边界、数据库迁移与重新打开、删除失败保护，以及创建/加入/回顾共享。

## 实现限制

- 中断文件保留原始字节，不保证设备在崩溃时已写出的最后一帧完整。用户完整试听后才可将现有片段确认为可整理；已丢失的声音无法恢复。
- JS 在后台可能被系统暂停，checkpoint 不是 Android 原生定时写入保证。原生录音服务与预写文件路径降低风险，仍需不同厂商真机实测。
- ASR 每段按当前模型的发言人区分限制控制在 2 小时内。任务失败时下次重新提交；网络中断保留远端任务 ID 继续查询。AI 整理没有独立 Android 后台任务服务，建议保持 App 前台。
- 百炼临时上传方案用于 MVP 验证，依赖服务可用性及临时文件保留规则；上线前应再次确认生产适用条件。
- 删除本地内容不会自动撤销云端已发布回顾；删除小程序保存资料不会改写已参加场次的历史资料快照，界面与隐私文档明确说明。
- 同名人物只在设备已有的 speaker 映射内检索，可能返回多个同名者的来源，来源保留场次供区分。

尚未达到 TASK.md 定义的“Android 真机 + 微信小程序 + BYOK + 搜索 + 共享回顾”最终完成标准。
