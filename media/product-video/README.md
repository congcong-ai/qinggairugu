# 倾盖如故产品介绍视频

使用 OpenFilm 0.2.6 制作，三个版本均为 36 秒、30 fps。

| 目录 | 用途 | 画幅 |
| --- | --- | --- |
| douyin | 抖音竖屏 | 1080 × 1920 |
| xiaohongshu | 小红书竖屏 | 1080 × 1440 |
| website | 官网横屏 | 1920 × 1080 |

每个目录的 `film.html` 是可编辑时间线，`shot-*.html` 是分镜，`assets` 是素材。MP4 在同目录。三个版本共用叙事，根据画幅调整布局，不是裁切横屏。

## 编辑与导出

进入对应目录，运行：

```sh
npx -y openfilm@0.2.6 open .
npx -y openfilm@0.2.6 look
npx -y openfilm@0.2.6 render --workers 4
```

系统中文旁白使用 macOS Tingting；轻音乐由代码合成，无第三方歌曲。截图来自本项目应用市场资料，截图中的交流内容为示例。视觉采用项目暖白与森林绿。

核心内容：线下交流痛点、本地录音、百炼 AI 整理、本机检索与来源、扫码认识同场参与者、确认后发布回顾。未声称小程序已正式上线或 iOS 可下载。

片尾引导官网了解产品与 Android 下载；小程序真实可用范围以实际微信版本为准。
